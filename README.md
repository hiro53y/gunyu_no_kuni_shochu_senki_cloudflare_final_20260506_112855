# 群雄ノ國：掌中戦記 4.1 ── 国盗り合戦絵巻

スマホ縦画面向けの、和風の国盗り合戦シミュレーションです。戦国の部隊合戦の定番（戦国ランスの合戦）の仕組みをそのまま写し、名前・絵・台詞は独自にしています。合戦は、ドット絵のちび武将と兵の集団が左右に並ぶ**最大6対6**。部隊ごとに技と標的を選び、遅れと硬直で回る手番、技数の旗、1行動で1つ減る時間の目盛り、戦果のバーで勝敗を争います。本陣は扇（行動）と武名、宣戦布告、国の命令（武将の能力の合計・持ち越し）、領地（野・町・城）、傷ついた兵、維持費で回します。黄泉沼の蛟王黒淵を討てば結末、全国を取れば天下統一。

## 合戦（戦国の部隊合戦の定番に合わせた決まり）

| 決まり | 内容 |
|---|---|
| 配置 | 前衛3・後衛3。武士・足軽・鉄砲・僧兵は前衛の列からしか攻撃できない。弓・忍者・軍師・巫女・陰陽は前後どちらからでも。騎馬はどこからでもどの敵へも |
| 手番 | 初めの遅れ＝兵種の遅れ＋速さ補正（速0で+8、1ごとに−2、速付与で−4）＋乱数1〜4（92%で+10、陰陽は+4）。次の手番＝今＋兵種の遅れ＋速さ補正＋技の硬直 |
| 時間 | 目盛り24。待機を含め1行動で1つ減る。延長戦+4・+6、時間経過−2、初期時間経過−5 |
| 打撃 | [補正兵数 ×（攻撃力−防御力）÷10] × 技の倍率 × 戦場補正。攻撃力＝兵種の攻＋攻×付与、防御力＝兵種の防＋防×付与×0.8。補正兵数は100未満を100、500〜は半分、2000〜は1/4の伸び。上限は兵数、下限は補正兵数の1/10 |
| 術 | 魔攻＋知 − 相手の知×0.7。ガードを無視 |
| 反撃 | 受けた側が反撃できる兵種なら［受ける前の兵数×（攻−相手の防）÷10］× 技の反撃率 |
| 回復 | ［補正兵数×知×0.06］× 倍率（戦果には入らない） |
| ガード | 足軽は初めから50%。同じ列（全体ガードなら全員）の物理を確率でかばって半分。かばうたびに−40%。100%以上なら必ず。自分はかばえない。全体攻撃はかばえない |
| 付与 | 軍師は初めに知の数だけ配る（知×5%）。合戦戦術は（2＋兵数÷300/200/100）個 |
| 戦果 | 100×（与えた打撃−受けた打撃）÷総打撃＋補正。守る側は野10・町20・城40を上乗せ、壊滅で+5 |
| 戦場補正 | 守る側の打撃に町+10%・城+20%。陣地構築・戦の準備で上乗せ（最大50%） |
| 捕獲 | 1合戦2人まで。基本1/5、落ち武者狩りで1/2、手加減突撃なら必ず（別枠1人）。名もなき将は捕まらなければ50%で討死 |
| 決着 | 全滅、時間切れ・技数切れは戦果（同点は守る側）、朔の部隊の壊滅は負け（本陣もおしまい） |

## 画面

- 合戦：上に戦果バーと行動順（技を選ぶと緑の▼で次の手番を予告）、まん中にちび武将の戦場（顔は立ち絵の丸い顔を実行時に縮めたドット、体と兵は兵種ごとに Canvas で描く）、下に12部隊の欄（小顔・兵数・技数の旗・ガード率・付与の矢印）と時間の目盛り。
- 操作：手番の部隊で敵（味方・自分）に触れると、使える技の小窓。技の札から選んで標的を選ぶこともできる。おまかせ、演出の速さ（ふつう・速い・なし）。
- 演出：駆け寄って斬り込む・槍で突く、矢・弾・手裏剣が飛ぶ、式神の群れ、矢の雨、回復の光、足軽が割って入るかばい、準備の輪と崩れ、防御式神、打撃の数字、倒れる兵、壊滅、技名の帯、消費「全」の大技は立ち絵のカットイン。

## 本陣

| 要素 | 内容 |
|---|---|
| 扇と武名 | 1季節に扇2つ。武名20・60・120で3・4・5つ |
| 国の命令 | 建設（統率・国力+1）、戦の準備（武力）、宣戦布告・人材探索・工作（知略）、説得（知略・扇なし）。5人まで、足りない分は持ち越し |
| 領地 | 国ごとに2〜5（野・町・城）。合戦1回で1つ。最後の城に城主。3季節ごとに1つ取り返される |
| 兵 | 減った兵は傷ついた兵。戦わなかった次の季節に戻る。手当て（10人あたり足軽1・他4文）、増員（兵種ごとの増員費）。上限＝（400＋50×国の数）×兵種の倍率 |
| 収入と維持費 | 収入は国ごとの年貢×（0.6＋国力×0.08）。維持費（1＋兵500ごとに+1）の合計が国力の合計を超えると半分 |
| 敵の手番 | 攻めてくるのは1季節に1度まで。迎え撃つか、家臣に任せる（おまかせの合戦） |

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run test       # Vitest（合戦の式と決まり・3,000戦の総当たり・国盗り）
npm run build      # tsc → vite build → dist/
```

- `BALANCE=10 npx vitest run tests/balance.test.ts`：国盗りを最初から最後まで自動で遊ばせて集計。
- `CAMPAIGN=4 npx vitest run tests/campaign.test.ts`：通しの自動プレイ（不変条件の検査つき）。
- 開発サーバーでは `window.__camp`（本陣）と `window.__battle`（合戦：`act`・`ai`・`field`）が使えます。本番のビルドには入りません。

## 構成

```text
src/
  battle/    合戦（DOM に依存しない純粋な TS。seed 付き乱数で決定的）
    types.ts 型   kinds.ts 兵種と技の表   engine.ts 手番・時間・打撃・ガード・準備・戦果・決着   ai.ts 敵とおまかせ
    view/      sprites.ts ちび武将・兵のドット絵   field.ts 戦場の描画と出来事の再生
  campaign/  国盗り：state（型）、army（能力・兵数・敵の部隊・技能）、campaign（扇・命令・出陣・結果・城下・ターン・敵の手番）、events（物語）
  content/   データ：sengoku（国・勢力）、generals（武将・兵種・台詞）、skills（固有技の名前と色）
  engine/    rng.ts（乱数）、save.ts（保存）
  ui/        画面（タイトル・本陣・地図・命令・陣立て・合戦・武将・城下・会話・結果・遊び方）
tests/       Vitest：battle / campaign / balance、campaignBot（自動プレイ）
```
