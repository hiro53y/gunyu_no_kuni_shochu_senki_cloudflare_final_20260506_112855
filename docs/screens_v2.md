# 群雄ノ國：掌中戦記 v2 画面ワイヤーフレーム

本書は v2 仕様（`spec_v2.md`）の画面設計を、テキストワイヤーで記述する。スマホ縦画面（360px）と PC 横画面（1280px以上）の双方を想定する。

## 1. 画面一覧

| 画面 | 役割 |
|---|---|
| タイトル | ゲーム起動時の入口 |
| 地図 | メインの行動選択画面 |
| 合戦 | 指揮官カード戦闘 |
| 武将詳細 | 武将のステータス・スキル・装備 |
| 内政・登用 | 自国地域の建設、徴収、浪人登用 |
| イベントログ | 過去ログの全件閲覧 |
| セーブ・ロード | データ管理 |
| 設定 | BGM・SE音量、文字サイズ、リセット |
| 結果 | 勝利・敗北時のリザルト |

カットインは0.8秒間表示後、自動で戦場に戻る。スキップは画面タップ。

### 4.3 戦闘演出フロー
1. 行動順アナウンス（画面上部に小さくフラッシュ）
2. 武将カードがハイライト
3. 行動コマンド選択（プレイヤー）／AI判定（敵）
4. 必殺技ならカットイン
5. ダメージ表示（数値ポップアップ）
6. HPバー減少アニメ
7. 撃破時はカードがフェードアウト＋灰化
8. 次の行動へ

### 4.4 敗走と勝利
- 全敵カードがHP0またはガード崩壊で敗走 → 勝利演出（旗倒し＋陣形ゲージ全染め）
- 自軍同様 → 敗北画面に遷移
- 30ターン経過時 → 総HP残量で判定、結果画面へ

## 8. デザインシステム

### 8.1 色

| 用途 | 色 | HEX |
|---|---|---|
| 背景・墨 | 墨黒 | #1A1A1A |
| 主要文字 | 生成 | #F5F1E8 |
| 強調・朱 | 朱赤 | #C84A4A |
| 金 | 古金 | #C9A24A |
| 自国 | 茜 | #C84A4A |
| 同盟 | 金茶 | #C9A24A |
| 敵対 | 紫紺 | #4A2C66 |
| 妖魔域 | 黒墨にじみ | #2A1A2A |

### 8.2 フォント
- 見出し: 毛筆系（例: Yuji Boku、Klee One）
- 本文: 明朝（例: Noto Serif JP）
- HUD数字: 等幅明朝

### 8.3 アイコン
- スキルアイコンは家紋風の単色シルエット
- ステータスアイコンは押印風のスタンプ

### 8.4 アニメーション
- 画面遷移: 暖簾めくり風（縦に下から上）
- カード出現: 半紙フェードイン
- 必殺カットイン: 立ち絵スライドイン＋朱の和柄エフェクト

## 9. アクセシビリティ
- 文字サイズ3段階（小・中・大）を設定画面に用意
- 色覚配慮: 勢力色は色＋家紋シェイプで二重識別
- アニメ無効化トグル

## 10. レスポンシブ・ブレークポイント
- 360px（スマホ縦・最小サポート）
- 768px（タブレット縦）
- 1024px（タブレット横）
- 1280px以上（PC・横画面）

各ブレークポイントで、地図・合戦・詳細の3画面が破綻なくレイアウトを切り替える。
