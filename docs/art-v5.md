# v5 イラスト素材

ユーザー承認の全面差替え範囲を、組み込み image_gen で制作。外部API・APIキーは使用していない。既存の良質な立ち絵・顔画像は参照し、元ファイルは保持した。

- `public/assets/v5/map.webp`：彩色した軍記絵巻風の八洲地図。海岸、北の雪山、北東の火山、森林、田畑、港、南東の魔境を描く。文字・勢力色はSVGで重ねる。
- `background_field/town/castle.webp`：野戦、町、城の横長背景。
- 固有武将22点：既存立ち絵の髪、装束、武器、顔立ちを参照した全身ちび武将。
- `commander_*`11点、`soldier_*`11点：兵種の違いが読める横向きの指揮官と一般兵。

キャラクターは透過768×512、256pxセルの3列2段。上段は待機・走り・攻撃、下段は被弾・退場・必殺。左右方向はゲーム側で反転する。姿勢ごとの共通倍率と足元基準を設定。セル間の微小な混入をアルファ連結成分で除去し、ゲーム表示倍率で確認した。

各生成指示・元生成ファイル名・完成ファイル名は `art-v5-manifest.json`。試作3点の補足指示は以下。

- 朔：黒い短髪、赤と黒の侍装束、刀。既存の風間朔立ち絵を参照した2.5頭身の横向き全身、明確な輪郭とセル塗り、透過6ポーズ。
- 鈴蘭：銀白色の髪と赤白の巫女装束、鈴・御幣。既存立ち絵を参照した同じ頭身・光源・輪郭の透過6ポーズ。
- 地図：和風戦国ファンタジーの島国を彩色軍記絵巻として描き、既存15国の位置関係に北の雪山、北東火山、南東の瘴気、南西の離島を対応。文字・UI・国境は焼き込まない。

寒月・黒淵・紅蓮は初稿の装束が立ち絵とずれたため再生成。緑の仏衣、黒金の妖魔衣、黒紅の妖姫衣へ合わせた。全48ファイル・264ポーズを点検し、元画像94ファイルのSHA256が基準と一致した。
