### 捕虜化・登用システム
- 戦闘終了時、敗北側の各撃破武将に対して独立に捕虜化判定
- 基礎30%、勝利側当主の魅力ボーナス、妖魔は-20%、浪人は+15%
- ユニーク武将は死亡10%、汎用は死亡25%、残りは捕虜or逃亡
- 捕虜は時間経過で忠誠ダウン（捕虜直後は5〜10%、10ターン後は60〜80%）
- 説得は金消費＋成功確率判定。失敗で忠誠ダウン＋次回必要金額アップ

### 汎用キャラの尖り設定
| 特性 | 出現率 | 主能力 | 説得難 |
|---|---|---|---|
| 平凡 | 60% | バランス型 | 標準 |
| 攻め手 | 12% | 武88-99／他低 | -5% |
| 守り手 | 7% | 統88-99 | -10% |
| 軍師 | 6% | 知88-95 | 標準 |
| 名将 | 4% | 全体エリート | -15% |
| 狙撃手 | 6% | 武80-92＋弓 | -5% |
| 暴れ者 | 3% | 武95-99／他極端 | -25% |
| 逸材 | 2% | 全部88以上 | -35% |

逸材は全能力 88-99、激レアで激ムズ説得。捕獲して登用できれば戦力が一気に飛躍する仕組み。

## 注意点

- 文字コードの問題：bash の heredoc やリダイレクトで日本語を書き込む際、稀に末尾に null バイトや UTF-8 不完全文字が混入する。出たら `tr -d '\000'` で除去。
- OneDrive 同期：`rm` `mv` がしばしば EPERM。ファイル内容の上書きは `cat > file` で問題ない。
- TypeScript の `as const` をリテラル配列で使う／関数引数を明示的に型付けすることで `rng.weighted` の戻り型が string に推論される問題を回避できる。
- `strict: true` 環境のため、`exactOptionalPropertyTypes` 周りは要注意。
