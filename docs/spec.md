# 仕様メモ

## プロジェクト
- タイトル: 群雄ノ國：掌中戦記
- 対象: スマホ縦画面360px幅を主対象とするWebゲーム
- 技術: Vite、React、TypeScript、CSS、localStorage、Netlify
- 表現: 和風戦国ファンタジー。既存商業作品の固有名詞や成人向け表現は使わない。

## MVP要件
- 12地域、プレイヤー勢力1、NPC勢力4、浪人枠1。
- 1ターンは1か月、毎ターン3AP。
- 行動は内政、徴兵、訓練、探索、登用、進軍、休養。
- ターン終了時に収入、維持費、ランダムイベント、NPC行動を処理。
- 勝利条件は8地域以上支配、または主要NPC勢力の全滅。
- 敗北条件はプレイヤー支配地域0、または60ターン経過時に3地域以下。
- セーブ、ロード、ニューゲーム、削除、自動セーブに対応。
- TypeScriptエラーなし、`npm run build` 成功を完了条件とする。

## 実装方針
- 型定義は `/src/types/game.ts` に集約する。
- 初期データは `/src/data` に置き、将来拡張しやすい配列構造にする。
- 乱数、戦闘、経済、NPC、勝敗、保存は `/src/engine` の純粋関数中心で実装する。
- UIはタブ式メイン領域と固定ヘッダー/固定アクションバーで構成する。
