# 群雄ノ國：掌中戦記 v5.0.1 仕様

八洲15国・8勢力・固有武将22名の戦国ファンタジー。React / TypeScript / Vite、Cloudflare Pages。既存URL・manifest・アイコン・APP HUB登録を維持する。

## 国取りと武将
初期行動2。合戦、内政、工作、探索、外交、交流に配分する。武将は1季節1回活動し、プレイヤーの行動後に続く敵手番にも使用済み状態を共有する。補充・部隊拡張・再雇用では回復しない。負傷者は活動できない。家臣上限30名。捕縛、牢、説得、登用、解放、解雇を使い分ける。

武名20ごとに軍議で褒賞を選択：毎季行動+1（合計最大5）、1500文、家臣レベル+2。受領数を保存し二重受領を防ぐ。部隊の兵数上限は（400+領国数×50）×兵種倍率+恒久拡張分。城下で有料拡張、戦勝でも少し成長する。拡張分最大8000。

外交は不戦・交戦・同盟・従属。知略の合計と友好で交渉し、足りない値は持ち越す。同盟の交易収入は1勢力100文、従属の貢納は領国基礎収入25%。従属領を覇道の統一条件に算入する。敵は季節ごとのランダム順に各勢力最大1回侵攻。同盟・従属は侵攻せず、その本拠への敵襲は自軍でも迎撃できる。失われた盟友は旧本拠を奪還して軍議で復興できる。

## 合戦
前衛3・後衛3の最大6対6。兵数、射程、技数、速さと硬直、制限時間、戦果で決着。近接反撃、足軽のかばい、鉄砲初弾、忍者の準備崩し、陰陽の準備、軍師付与、巫女回復を維持する。自動配置は近接兵種を前衛に優先。部隊を選んで技・対象・消費・硬直・予想打撃幅・反撃情報を確認する。

通常/速い/なしの演出設定を統一。背景3種、駆け寄り・兵の攻撃・飛び道具・被弾・壊滅・固有技カットイン。非表示・破棄時に未完了アニメーションを解放し、復帰を妨げない。命令の重複武将、行動済み武将、二重入力、未完了/別seed/二重の結果反映を拒否する。

## 分岐と周回
人間勢力の元の本拠を初めて攻略・解放後にルート選択可能。軍議に開放条件と進捗を表示し、選択を保留できる。

|道|開放|結末|
|---|---|---|
|覇道|本拠攻略|全15国を自領・従属領にし黒淵討伐|
|盟約|本拠攻略+人間2勢力と同盟・従属|旧本拠を保持する盟友3勢力以上+黒淵討伐|
|鎮霧|本拠攻略+鈴蘭の絆2+焔ノ家か蓮華院と協力・制圧|鈴音山・焔ノ郷を封印、黄泉沼の専用最終戦、黄泉沼封印|

ルートごとの中盤会話・最終戦補正・結末、勢力別攻略会話、占領後の帰順/徴収、盟友落城/復興、攻略順による解放会話を実装。封印は未行動の巫女・陰陽・僧兵が代行できる。会話の発火キーを記録。既読は完了・スキップ時に記録する。

結末1回につき周回ポイント3。新規開始時にポイント1で初期資金1000文、汎用家臣1名、初期武将レベル+1のいずれかを選べる。領土・軍団は引き継がない。既読・称号・到達した結末を保持する。

## 保存と画像
v5専用 `gunyu5:campaign/battle/turnstart/settings/chronicle`。本陣形式4、合戦形式2。旧キーは削除しない。自動保存・つづきから、季節開始のやり直し。保存失敗でもメモリー上の進行を止めず、起動確認・復元・バックアップ画面は追加しない。

彩色地図+SVG国境/所有色/城/名前/街道/侵攻予告。表示とタップ領域を共用し、拡大・縮小・全図を提供。固有22・汎用指揮官11・一般兵11の透過アトラスは各6ポーズ。既存立ち絵等94ファイルを保持。素材は docs/art-v5.md と同manifestを参照。

## 原作資料と独自仕様
[公式システム説明](https://www.alicesoft.com/rance7/special05.html)で初期2行動、全勢力で1ターン、武将1回活動、攻防人員共用、家臣最大30、複数領地と最後の城の考え方を確認。[公式合戦紹介](https://www.alicesoft.com/rance7/special.html)で対象部隊からの行動選択、味方の回復/ガード、足軽の同列かばいを確認した。

本作の能力、打撃式、反撃率、技・時間・収入・外交閾値・成長・ルート・最終戦補正は八洲向けの独自設定。原作と同一の数式・難易度とは主張しない。人物・会話・絵・音楽は本作の独自表現を使う。

## v5.0.1 描画修正
アトラスの256pxセルを縮小せず保持し、80pxの武将・40pxの兵という表示寸法だけを描画時に指定する。中間/最終CanvasともdevicePixelRatio（最大3）に合わせた画素数とし、CSS解像度への中間縮小と引き伸ばしを避ける。同寸法のResizeObserver通知ではCanvasを再初期化しない。

操作待ち/技演出/敵手番/決着を通じてフッター領域と行動順の高さを確保する。技数が多い場合は技欄内部でスクロール。画面全体の閃光・揺れと被弾時の白い四角形を撤去し、対象付近のヒットマーク・斬撃・粒子とカットインで示す。保存キー・合戦ルール・画像素材自体は変更しない。
