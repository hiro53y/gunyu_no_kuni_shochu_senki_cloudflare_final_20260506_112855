# 群雄ノ國：掌中戦記 v2 仕様書

## 0. ドキュメントの位置付け
本書は v1 仕様（`spec.md`）の後継にあたる。v1 はMVPとして「動く国盗りSLG」を作り切ることを目的としていたが、操作性・視覚的訴求力・戦闘の手応えに課題があった。v2 では伝奇ファンタジー寄りの世界観に踏み込み、合戦システムを「指揮官カード戦闘」へ拡張し、UIを抜本的に作り直す。

## 1. プロジェクト概要
- タイトル: 群雄ノ國：掌中戦記
- ジャンル: 和風伝奇ファンタジー国盗りSLG（軽量ターン制SLG＋指揮官カード合戦）
- 対象端末: スマホ縦画面（360px幅）優先、タブレット横画面・PCブラウザにも対応
- 技術: Vite + React + TypeScript + CSS、localStorage、Cloudflare Pages（Netlify互換）
- 創作方針: 完全オリジナルの和風伝奇世界として構築する。ジャンルとしての設計パターン（軽量ターン制SLG、指揮官カード戦闘、伝奇ファンタジー三つ巴構造）は積極的に踏襲するが、既存作品からのキャラクター名・立ち絵・ロゴ・UIアセットの直接的な流用は行わない。

## 2. 世界観の骨格
舞台は架空の島国「八洲（やしま）」。数百年前の「黒淵の災（くろぶちのわざわい）」を境に神々の力が衰え、各地に妖魔が湧き出す乱世となった。三つ巴の構造を基本とする。

| カテゴリ | 概要 | 役割 |
|---|---|---|
| 人間勢力 | 暁ノ家（プレイヤー）＋人間NPC勢力5 | プレイヤーの主敵かつ同盟相手 |
| 異形勢力 | 妖魔の群、僧兵衆「蓮華院」 | 戦略的な脅威・常設の敵対要素 |
| 中立勢力 | 浪人衆 | 人材供給源、雇用先 |

詳細は `world_v2.md` を参照。

## 3. ゲームの基本ループ
1. 地図画面で行動コマンドを選び、AP消費型の行動を実行する
2. AP切れ、または手動でターン終了を実行
3. ターン終了処理：収入、維持費、満足度変動、ランダムイベント、NPC勢力の自律行動、勝敗判定
4. 次ターン開始

| 要素 | 値 |
|---|---|
| マップ地域数 | 15地域 |
| 勢力総数 | 8（プレイヤー1、人間NPC5、妖魔1、浪人1） |
| 1ターン | 1か月 |
| 1ターンあたりAP | 3（武将育成・建設で最大5まで拡張） |
| 想定プレイ時間 | 1周 60〜90ターン、3〜4時間 |

## 4. 勝利・敗北条件
- 勝利: 全15地域中12地域以上を支配、または妖魔の群の本拠「黄泉沼」を陥落させ首領を撃破
- 敗北: プレイヤー支配地域0、または90ターン経過時点で支配地域5以下

## 5. 行動コマンド（地図画面）
| コマンド | 概要 | AP | 制約 |
|---|---|---|---|
| 合戦 | 隣接する非自国地域に進軍。合戦画面に移行 | 1 | 隣接条件 |
| 建設 | 自国地域の国力をUP（収入・兵糧上限・徴兵上限が増加） | 1 | 自国地域のみ |
| 徴収 | 自国地域から金を一時徴収。満足度ダウン | 1 | 自国地域のみ |
| 探索 | 地域を探索。人材・遺物・隠しイベントが発生 | 1 | 自国・通行可地域 |
| 調略 | 敵地域へ調略を進める。同地域に複数回投入で寝返り発生 | 1 | 隣接敵地域 |
| 登用 | 浪人や捕虜を仲間に加える | 0または1 | 対象が登用枠にいる場合 |
| 休養 | 武将のスタミナと兵数を回復 | 0 | 任意 |
| ターン終了 | 残りAPを破棄しターン終了 | — | 任意 |

## 6. 合戦システム（指揮官カード戦闘）
v2 の中核となる戦闘画面の仕様。

### 6.1 配置
- 3行×3列の指揮官スロット。プレイヤー側は画面左、敵側は画面右に対面で配置
- 各スロットに武将1人と部隊（兵数）が紐づく
- カードに表示する情報: 武将名、HP（兵数）バー、ガード％、コスト、スキルアイコン2、状態異常

### 6.2 進行
- 行動順は各武将の「素早さ」を基準に1ティック単位で進行する
- 1ターンの間に素早さの高い武将は複数回行動が可能
- 行動コマンド: 通常攻撃、スキル1、スキル2、ガード、撤退

### 6.3 スキル分類
| 区分 | 例 |
|---|---|
| 単体攻撃 | 一閃、火槍突撃、狙撃 |
| 範囲攻撃 | 全体斬り、火炎陣、轟雷 |
| 補助 | 鼓舞（味方攻撃UP）、結界（味方ガードUP） |
| 回復 | 神薙ぎ（単体回復）、祓い（全体回復＋状態異常解除） |
| 特殊 | 暗殺（即死判定）、調伏（妖魔系特効） |

### 6.4 演出
- 必殺技発動時、画面左上または右上に立ち絵カットイン＋台詞ウィンドウを表示
- 撃破時のシルエット消滅エフェクト、敗走時の旗倒しエフェクト
- BGMは平時／合戦／妖魔戦の3トラック切替

### 6.5 戦場補正
地形ごとに勝率補正を加える。例: 山岳地で弓スキル+10%、沼地で機動低下、神域で僧兵系+15%。

### 6.6 終了条件
- どちらかの全武将がHP0または撤退
- 上限ターン（30ターン）経過時、総HP残量で判定

### 6.7 捕虜化判定
合戦終了時、敗北側の撃破された武将について、勝利側がそれぞれ独立に捕虜化判定を行う。

| 要素 | 値 |
|---|---|
| 基礎捕虜化確率 | 30% |
| 勝利側当主の魅力ボーナス | (魅力 - 50) × 0.5%（上限+25%、下限-15%） |
| 大差勝利ボーナス | 残HP比80%以上の場合 +10% |
| 妖魔勢力に対する補正 | -20%（妖魔は基本的に捕らえない／消滅扱い） |
| 浪人衆 | 一律+15%（金で動く性質のため捕虜化されやすい） |

ユニーク武将（22名）は死亡判定が10%、その他90%が捕虜化または逃亡。汎用武将は撃破時25%が死亡、残りで上記判定。死亡判定が出た武将は二度と再登場しない。

## 6A. 説得・登用システム
プレイヤーが抱える捕虜は内政・登用画面で説得を試みられる。

### 6A.1 説得の流れ
1. 対象捕虜を選択
2. 必要金額を支払う（基礎500金 + 武将の魅力 × 20金 + 試行回数 × 200金）
3. 成功判定（プレイヤー当主の魅力 + 捕虜状態日数 - 元勢力への忠誠 + 乱数）
4. 成功なら自勢力に登用、失敗なら忠誠ダウン＋次回必要金額アップ

### 6A.2 成功率の目安
| 状態 | 成功率の目安 |
|---|---|
| 捕虜直後・忠誠80以上 | 5〜10% |
| 捕虜数ターン経過・忠誠50前後 | 25〜45% |
| 捕虜10ターン以上・忠誠30以下 | 60〜80% |
| 元勢力滅亡 | +30%（戻る場所がないため） |
| 妖魔系 | 一律不可（除く一部例外） |

### 6A.3 登用済み武将のふるまい
- 自勢力武将として通常運用可能
- 元勢力との合戦時、忠誠が一時的に下がる（裏切りリスク）
- 元勢力が再興した場合は説得逆方向のリスクあり（v2範囲外、後日拡張）

## 6B. 汎用キャラクター
NPC勢力の戦力補強として、ユニーク武将以外に汎用キャラが登場する。これは戦国期日本人風の名前が自動生成され、勢力の人材プールに追加される。

### 6B.1 汎用キャラの特性プロファイル
| 特性 | 武力 | 統率 | 知略 | 魅力 | 出現率 | 備考 |
|---|---|---|---|---|---|---|
| 平凡 | 50-70 | 50-70 | 40-65 | 40-65 | 60% | バランス型 |
| 攻め手 | 88-99 | 30-55 | 25-50 | 30-60 | 12% | 武力極振り |
| 守り手 | 60-75 | 88-99 | 50-70 | 50-70 | 7% | 統率極振り |
| 軍師 | 30-50 | 50-70 | 88-95 | 50-70 | 6% | 知略極振り |
| 名将 | 70-85 | 88-95 | 60-78 | 70-85 | 4% | エリート総合型 |
| 狙撃手 | 80-92 | 50-70 | 60-75 | 40-60 | 6% | 弓・狙撃スキル付き |
| 暴れ者 | 95-99 | 25-45 | 15-35 | 20-40 | 3% | 武力最強だが他極端、説得難 |
| 逸材 | 88-99 | 75-95 | 75-95 | 70-95 | 2% | 全能力高い当たり、説得激難 |

### 6B.2 出現契機
- NPC勢力が地域を保持して10ターンごとに1〜2人補充
- プレイヤー勢力地域でも探索成功時に5%で「人材発見」イベント
- 浪間（浪人衆地域）からは登用画面で常時2〜4人が雇用候補に並ぶ

### 6B.3 捕獲の楽しさ
「暴れ者」と「逸材」は遭遇率が低いが、捕獲して登用に成功すれば戦力が一気に飛躍する。逆に説得難度が高く、何度も金を溶かす羽目になる。これがv2の中核的なリプレイ要素。

## 7. UI構成

### 7.1 共通HUD（画面下部固定）
ターン、年月、AP残、金、兵糧、満足度、得点（支配地域数×係数＋イベント加点）。

### 7.2 地図画面
- 中央: 八洲マップ（勢力カラー塗り分け、地域アイコン、進行中の戦線エフェクト）
- 左サイド: イベントログ（直近10件）と作戦リスト（進行中の調略・建設・探索の進捗％）
- 右サイド（横画面時のみ）: 凡例（自国／従属国／同盟国／隣接国／敵対国／妖魔域）

### 7.3 合戦画面
- 中央: 陣形ゲージ（敵味方の兵力差を視覚化する横軸ゲージ）
- 左右: 3×3スロット
- 上部: 戦場補正と地形名
- 下部: 行動コマンドボタン、ログウィンドウ

### 7.4 武将詳細画面
- 立ち絵、名前、所属、ステータス（統率・武力・知略・魅力）、スキル一覧、装備、忠誠、関係性タグ

### 7.5 タイトル画面
- ロゴ、ニューゲーム、コンティニュー、ロード、削除、設定、クレジット

## 8. データ構造（要点）

### 8.1 型定義（`src/types/game.ts`）
- `GameState`: ターン、勢力一覧、地域一覧、武将一覧、ログ、設定
- `Region`: 地域ID、名前、所属勢力ID、国力、満足度、特産、地形、隣接地域ID配列
- `Faction`: 勢力ID、名前、当主武将ID、勢力カラー、AI傾向タグ、外交関係
- `General`: 武将ID、名前、所属勢力ID、ステータス、スキルID配列、兵数、スタミナ、忠誠、立ち絵キー、状態
- `Skill`: スキルID、名前、種別、対象、効果式、消費、説明文
- `BattleState`: 場所、プレイヤー陣、敵陣、ターン、ログ、結果
- `SaveData`: version、createdAt、GameState

### 8.2 初期データ（`src/data/`）
- `regions.ts`、`factions.ts`、`generals.ts`、`skills.ts`、`events.ts`
- 配列＋IDキー方式で記述する

### 8.3 純粋関数エンジン（`src/engine/`）
- `economy.ts`: 収入・維持費・満足度変動
- `battle.ts`: 合戦の進行とダメージ計算
- `npc.ts`: NPC勢力の意思決定
- `event.ts`: ランダムイベント発生
- `save.ts`: シリアライズ・デシリアライズ・version検査
- `rng.ts`: シード固定可能な乱数

## 9. セーブ仕様
- 手動セーブ＋自動セーブ（ターン終了時）
- セーブデータ: `{ version: number, createdAt: ISOString, state: GameState }`
- ロード時 version 不一致の場合は移行関数を試み、失敗時はロード拒否し画面を保つ
- 削除はワンクッション確認
